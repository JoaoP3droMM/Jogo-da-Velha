# Jogo da Velha com Deep Learning

Este projeto é uma implementação de um **Jogo da Velha (Tic-Tac-Toe)** utilizando **JavaScript** e **TensorFlow.js** para criar uma inteligência artificial que joga contra o usuário. Além disso, o jogo também oferece um modo **Jogador vs Jogador**.

## Funcionalidades

- **Jogador vs IA**: Um jogador pode competir contra uma inteligência artificial treinada usando deep learning.
- **Jogador vs Jogador**: Dois jogadores podem jogar entre si no mesmo dispositivo.
- **Interface Interativa**: Um design simples e funcional para facilitar a jogabilidade.
- **IA Aprimorada**: A inteligência artificial toma decisões com base em um modelo de aprendizado de máquina treinado para maximizar suas chances de vitória.

## Tecnologias Utilizadas

- **JavaScript**: Linguagem principal do projeto.
- **TensorFlow.js**: Biblioteca para implementar e executar o modelo de deep learning no navegador.
- **HTML/CSS**: Para a interface do jogo.

## Como Executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/JoaoP3droMM/Jogo-da-Velha.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd Jogo-da-Velha
   ```
3. Abra o arquivo `index.html` no navegador para iniciar o jogo.

## Pré-requisitos

- Um navegador atualizado (recomenda-se o **Google Chrome** ou **Firefox**) com suporte para TensorFlow.js.
- Conexão com a internet para carregar bibliotecas externas, caso aplicável.
